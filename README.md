## 🚀 Getting Started

**Prerequisites:**  Node.js (v18+)

1. **Clone and Install:**
   `npm install`
2. **Configure Cognitive Parameters:**
   Create a `.env.local` file in the root directory and insert your Gemini API key:
   `GEMINI_API_KEY=your_api_key_here`
3. **Initialize the Node:**
   `npm run dev`
